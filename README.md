# 名字竞技场

这是一个从零开始重建的、独立的名字竞技场网页项目。该仓库不再是任何上游项目的 Fork。

当前版本仅包含可发布的静态网页入口，用于确认 GitHub Pages 发布链路。后续将采用以下方向：

| 层级 | 技术方向 | 职责 |
|---|---|---|
| 战斗内核 | C++ + WebAssembly | 角色属性、技能、状态、回合结算与战斗事件 |
| 网页界面 | TypeScript + React | 阵容编辑、战斗可视化、日志与配置管理 |
| 发布 | GitHub Pages + GitHub Actions | 自动构建并发布静态网页与 WASM 资源 |

## 状态

项目已完成独立仓库初始化，等待战斗规则与界面需求确定后开始实现。
