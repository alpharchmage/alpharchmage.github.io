# 参考页面结构映射

本文件依据公开的 Rosmontic `index.html`、`md5.html` 与 `md5.css` 建立结构映射。新项目只采用层级、尺寸与信息组织方式；不引用原始页面的脚本、图片、SVG data URI 或样式文本。

| 参考 DOM 区域 | 可见职责 | 新 React 组件 | 独立实现约束 |
|---|---|---|---|
| `.body` | 页面运行时承载区 | `ArenaApp` | 纯 React 根节点，不使用 iframe |
| `.panels > #inputPanel.panel.vertical` | 320px 居中蓝色启动面板 | `StartPanel` | 复刻尺寸、留白、渐变与控制层级 |
| `#inputtitle.paneltitle` | 白色标题 | `StartPanelTitle` | 文案与字体栈独立实现 |
| `#textdiv > textarea` | 多行名字输入 | `NameInput` | 保留原始文本、空行和顺序 |
| `.inputoptions` / `.bossList` | 可折叠特殊名字选择区 | `SpecialNameMenu` | 首版只显示已识别的特殊名字说明 |
| `.goBar` | 底部操作区 | `StartControls` | 复刻左开关、中开始、右添加的空间关系 |
| `.controlbar` | 战斗态右上角控制条 | `BattleControls` | 快进、返回、分享以独立 CSS 图形呈现 |
| `md5.html > .main` | 战斗页根节点 | `BattleScreen` | 无 iframe、纯组件化布局 |
| `.plist` / `.hlist` | 左侧单位列表 | `RosterRail` | 200px 桌面轨道；窄屏移至顶部 |
| `.pbody` / `.hbody` | 主战斗信息区 | `BattleMain` | 标题、属性行、浅蓝分隔线与日志连续呈现 |
| `.plr_list` / `.plr_body` | 单位名、属性和细生命条 | `CombatantLine` | 16px 标记与 2px 生命条独立绘制 |
| `.damage` / `.recover` / `.stext` | 语义事件文本 | `BattleEventLine` | 红、绿、蓝仅用于事件意义 |
| 结果表 | 胜者与战绩 | `ResultSummary` | 放在事件流末尾，不创建大结算卡 |

## 关键尺寸

启动面板按 320px 宽、8px 内边距、10px 圆角和约 304px 输入宽度实现。底部控制条高 30px，开始按钮宽 100px。战斗页在桌面端使用 200px 左侧单位轨道，主区占据其余空间。文字排版以 15px 基准字号、16px 行高和等宽回退字体为准。

## 多人输入实测补充

使用四个中文名字、以一个空行分成两队时，参考输入框将每个名称逐行原样展示，空行只承担队伍分隔语义，不显示额外组标题、边线或队伍标签。新项目应同样保存原始文本与空行位置，既不能排序，也不能在开始前自动将分队视觉卡片化。

## 多人对局实测补充

四人战斗开始后，左侧单位轨道按输入顺序垂直显示四个名字；同队采用相同的像素旗帜色，另一队采用另一种旗帜色。右侧属性行也严格保留同一顺序。攻击日志只在造成伤害或触发明确关系事件时增加一行，攻击者与目标各自带有同款 16px 图标；伤害数字保持红色。多人战斗中，队友关系以一行紧凑文本插入常规攻击日志，不创建额外弹窗或特效层。

## 特殊名称输入实测补充

将 `AL1S@!` 与普通名字分队输入时，启动页文本框不对特殊名称作额外高亮、替换或卡片化处理；它与普通文本保持同样的逐行样式。新项目也应在输入阶段维持这种克制呈现，只在战斗页的属性行或事件流中通过很小的语义标记说明该单位被特殊规则识别。

## 特殊 Boss 对局实测补充

`AL1S@!` 在战斗启动后显示为其角色名“天童爱丽丝”，而非输入代码本身；它在左侧单位栏和属性行均使用该显示名，并在属性行末尾附加一个极小的特殊图标。技能行动仍以紧凑单行日志呈现，例如角色名、蓝色技能短句和受击/伤害文本顺序连续排列。结算表的胜者与败者采用两个独立细表头，胜者名称旁保留小型状态图标；特殊单位不会获得大角色卡、全屏立绘或额外的结算页面。

## 新实现启动页初步比对

新 React 页面已经复刻了白底、居中窄蓝青面板、白色大输入框、左侧 Boss 复选、居中灰色“开始”胶囊按钮和右侧圆形加号的结构。与参考的初始状态一致，输入特殊代码时不出现额外的卡片或高亮；下一步需重点比对战斗态的字距、左侧轨道高度和结果表列宽。

## 新实现战斗页比对

以“观察者”对“AL1S@!”启动新回放后，特殊代码会转换为“天童爱丽丝”，其固定属性行、左侧单位栏和行末微型状态标记均按参考信息层级呈现。新页面保持 200px 左侧轨道、白色主日志区、浅蓝横线、右上双控制键和日志末端双表头结算。回放由 480ms 间隔逐条追加，快进按钮会立即展示完整事件与结算，符合参考游戏“自动播放、用户可快进”的行为模式。
